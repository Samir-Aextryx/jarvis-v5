# JARVIS v5

Lokaler, voice-first KI-Desktop-Assistent (Windows, Electron) mit Wake-Phrase,
Sprachein- und -ausgabe und mehreren KI-Anbietern. Dieses Repo enthält die
**Dokumentation** und die **Präsentation**; die fertige App gibt es als
Download unter *Releases*.

## ⬇️ Download

Die fertige Windows-App (`Jarvis v5.exe`) findest du unter
**[Releases](../../releases/latest)**.

> Hinweis: API-Keys werden nicht mitgeliefert — sie werden lokal im
> Windows Credential Manager gespeichert.
